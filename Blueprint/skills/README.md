# Blueprint authoring Skills

## Create AtomicBehavior manifest

Use [create-atomicbehavior-manifest](create-atomicbehavior-manifest/SKILL.md) to author a complete Blueprint AtomicBehavior manifest and its referenced artifacts.

The companion starter template is [atomicbehavior/templates/manifest.yml](../atomicbehavior/templates/manifest.yml). Treat it as a starting point, not as a substitute for the authoritative schema or a repository-specific manifest.
