# Changelog

## [1.0.0] - Unreleased

### Added
- semantic commerce runtime and executable graph/governor gates;
- purchase, inventory, sale, financial, customer, supplier, fiscal/accounting projection flows;
- persistence, event delivery/replay and application/channel adapters;
- Evolution Go WhatsApp ingress, conversation orchestration and traceable media extraction;
- responsive Web UI for dashboard, products/stock, purchases/suppliers, sales/customers, finance/reporting and administration;
- search/filter/export, real-time notifications, accessibility and offline resilience;
- audit/observability, security hardening, backup/restore/DR and performance acceptance;
- deterministic sandbox, operator/incident/deployment runbooks and reproducible production deployment;
- E2E, staging-pilot evidence and real-operator acceptance gates.

### Release policy
`v1.0.0` remains unreleased until all final-gate inputs are green, including real staging pilot and real non-developer operator evidence.
