# Generator

Generates implementation, schema, and test projections.

For authoring the semantic source manifest before generating projections, follow [Create AtomicBehavior Manifest](../../skills/create-atomicbehavior-manifest/SKILL.md) and start from [the AtomicBehavior manifest template](../../atomicbehavior/templates/manifest.yml). The generator must not infer or silently invent the canonical function or canonical scenario; collect them from the user when they are not already established.
